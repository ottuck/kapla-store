## 3. 기능 요구사항

### 회원 (기본 등급 1)
- 가입 시 ID, PW, PW 확인, E-mail 필수
- Q&A 질문 등록·수정·삭제, 공지 조회
- 이벤트 배너 → 이벤트 상품 페이지 접속
- 상품 조회, 장바구니, 찜, 구매
- My Page: 회원정보 조회·수정·탈퇴, 교환·환불 신청 내역

### 관리자 (기본 등급 0)
- 모든 게시판 CRUD (Q&A 답변, 공지, 이벤트)
- 상품·상품 설명·수량 등록·수정·삭제
- 주문 조회, 환불 신청 수락·거절(답변 포함), 교환 신청 대응

### 데이터 모델 (ER 다이어그램)
회원, 상품, 주문, Q&A 게시판, 공지·이벤트의 5개 엔티티. 회원 1 : N Q&A, 회원 M : N 상품(주문).

## 4. 디자인 특징 (Before 자료)

- 브랜드명: Kapla (필기체 로고), 갈색 계열 포인트 컬러(IA 다이어그램)
- 메인: 일몰 풍경 영상을 전체 화면 배경으로 사용, 나머지 화면은 단순한 레이아웃
- 상품 컨셉: 오일 퍼퓸 등 향수 중심, 헤어 스타일 모델 사진 사용
- 가격·배송비: 원화(₩), 택배 선결제, 금액별 배송비

## 6. 재사용 금지 및 주의 사항

- **상품·브랜드 이미지**: 장바구니·주문서 화면의 상품과 가격은 실제 브랜드에서 가져온 것이므로 사용하지 않는다. 새 가상 브랜드와 AI 생성 또는 무료 라이선스 이미지를 사용한다.
- **모델 사진**: 헤어 모델 사진은 출처가 불분명하므로 재사용하지 않는다.
- **메인 히어로 영상(우유니 사막 일몰)**: 사용자가 저작권 문제가 없는 것으로 직접 구한 영상이라 **그대로 사용한다**(2026-10-26 사용자 확인). 영상 파일은 저장소에 없으므로 사용자가 제공하고, 출처·라이선스 정보를 `docs/`에 기록해 둔다.
- **개인정보**: 목업 푸터에 실제 전화번호, 이메일, 사업자등록번호, 통신판매업 신고번호, 주소가 있다. 공개 데모에는 가상 도쿄 주소와 더미 정보만 쓰고, Before 자료로 원본 목업을 보일 때는 해당 부분을 가린다.
- **팀 프로젝트**: 원본은 3인 작업이다. 포트폴리오에서 팀 기여와 리메이크 개인 기여를 구분해 표기한다.
- 저장소의 `1.UML/요건정의서.xlsx`는 호텔 예약 시스템 양식으로, Kapla 쇼핑몰 요구사항이 아니다. 참고하지 않는다.

## 6-1. 원본 소스 코드에서 확인한 것 (`globalinFinal`)

Spring Boot + JSP + MyBatis + Oracle. 주요 화면은 `main`, `brand`, `event`, `directions(오시는 길)`, `itemlist`, `product_detail`, `order/cart·order·success`, `mypage/*`, `customerservice`, `qa`, `notice`, `user/login·signUp`이다.

- **카테고리**: 오일 퍼퓸(1), 핸드 퍼퓸(2), 홈&트래블(3, 하위: 디퓨저·카 디퓨저·캔들), 기프트(6)
- **상품 상태 라벨**: `Limited Edition` / `Signature` / `New` (리메이크: 상품 태그 `限定` / `シグネチャー` / `新作`)
- **상품 상세**: 상태 라벨, 상품명, 가격, 접이식 "제품 세부 정보"(전성분·사용방법·주의사항·상세정보), 접이식 "배송 & 반품", 수량 선택과 총 금액, 「장바구니」「바로구매」 버튼, 관리자 전용 「상품 변경」
- **배송 정책(원본)**: 배송비 3,000원, 4만원 이상 무료, 교환·반품비 6,000원, 배송 1~3일 (리메이크: 송료 500엔, 8,000엔 이상 무료)
- **이벤트**: 월별 배너 이미지(1월·2월)가 기프트 카테고리로 연결됨
- **브랜드 페이지**: 이미지 2장(브랜드 이미지, 문구 이미지)으로 구성된 단순한 페이지
- **고객센터**: 자주 묻는 질문 목록(클릭하면 답변이 펼쳐지는 표), 공지사항, Q&A 게시판
- **헤더**: 영상 위에 겹치는 흰색 메뉴(Brand, Shop / 로고 / Event, Store), 우측 Login·Join·Cart
- **이미지**: 상품·브랜드·이벤트 이미지(약 41MB)는 실제 브랜드 이미지가 섞여 있어 재사용하지 않는다.

## 7. 리메이크 결정 사항 (확정)

- 사이트 언어 일본어, 통화 JPY(소수점 0자리), 세금은 税込 표시
- 특정상거래법 표기, 개인정보 처리방침 페이지는 더미로 작성
- 결제는 테스트 모드만, 공개 데모에는 `noindex`와 「デモサイト」 표시
- 공개 방식(갱신): Local에서 결제 흐름(Stripe 테스트)까지 완성한 뒤 **M1 홈서버(Docker Compose + Cloudflare Tunnel)** 로 이전해 공개한다. Playground는 파이프라인에서 제외하고, 서버가 꺼졌을 때의 대체 데모 정도의 선택 사항으로 둔다. 주소는 `kapla.portfolio-hub.dev` 후보
- 기존 Lightsail 인스턴스에는 넣지 않는다(메모리 여유가 적다). 월 약 1,000엔 이상의 추가 지출은 하지 않으며 유료 공유호스팅은 계약하지 않는다(조사: `docs/hosting-reference.md`)
- **PHP는 8.5.12를 유지한다**(사용자 결정, 2026-10-26). 일본 공유호스팅 조사(`docs/hosting-reference.md`)는 나중에 고객 납품 호스팅을 조사하는 수고를 덜기 위한 사전 조사일 뿐이며, 납품 시점에 대상 호스팅 PHP로 호환 테스트를 한다.
- 홈서버: MacBook Air M1(Docker, RAM 8GB) 위에서 컨테이너로 운영하고, 포트는 외부에 직접 열지 않고 터널을 통해서만 공개한다. 컨테이너별 메모리 제한을 둔다. 자세한 구성은 Git에 두지 않는 별도 문서에 있다
- WordPress는 MySQL/MariaDB만 공식 지원하므로 기존 Postgres를 쓰지 않고 MariaDB를 별도로 둔다
- Playground는 WooCommerce 실행 시점 설치 시 첫 로딩이 30~60초일 수 있어(공식 문서), 빌드에 포함하는 방식과 Cloudflare Pages 파일 크기 제한(파일당 25MiB로 알고 있음)을 확인해야 한다
- 작업 방식: Claude가 구현하고 사용자는 결과물과 관리자 화면을 확인
- 디자인 방향: **A. Warm Editorial** 확정 (크림 바탕, 테라코타 포인트, 세리프 제목, 원본 영상 히어로, Kapla 로고는 처음에 Lobster 필기체였으나 2026-10-26에 Cormorant Garamond 대문자 로고타입으로 변경). 브랜드명은 영문 Kapla, 상품 이미지는 사용자가 AI로 생성
- 히어로 영상 원본 위치: 팀 소스 저장소 `EmperorBug/globalinFinal`(공개)의 `src/main/resources/static/img/mainVideo.mp4` (약 7.1MB).
