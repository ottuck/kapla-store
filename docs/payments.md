# 결제·배송 설정과 테스트 현황

> 갱신: 2026-10-26 · 로컬(`kapla.local`) 기준. 실제 결제는 하지 않고 테스트 모드만 쓴다.

## 현재 상태

| 항목 | 상태 |
|---|---|
| 통화·세금 | JPY(소수점 0), 가격 税込 입력·표시, 消費税 10% |
| 배송 지역 | 일본만 (`日本` 존) |
| 송료 | 전국 일률 500엔(데모에서는 비과세로 취급해 500엔 정확히 표시). **8,000엔(税込) 이상은 무료**. 무료 조건을 만족하면 유료 송료는 선택지에서 숨긴다 |
| 대금상환(代金引換) | 활성(Stripe 키 설정 전에도 주문 흐름을 확인하기 위한 용도) |
| Stripe | `woocommerce-gateway-stripe` 11.1.1 설치·활성(PHP 8.5.12, WP 7.1.3, WC 11.2.1에서 오류 없음). **테스트 키 설정 완료**(샌드박스, JPY), 테스트 카드 결제 성공 |
| 체크아웃 | 블록 방식. 일본 주소 입력란(姓·名, 郵便番号, 都道府県, 市区町村, 住所) 정상 |

## 확인한 주문 흐름 (대금상환)

1. `SALAR 塩湖 オイルパフューム`(¥5,500) 장바구니 → 체크아웃 → 주문 확정
2. 주문 #37: 상태 `processing`, 합계 ¥6,000(송료 ¥500 포함, 소비세 ¥500 포함), 결제 방법 `cod`, 통화 `JPY`
3. 주문 완료 화면에 주문 번호·금액·배송지가 일본어로 표시됨
4. `ギフトセット`(¥8,800)로 확인: 무료 송료만 표시되고 합계 ¥8,800

## 확인한 주문 흐름 (Stripe 테스트 카드)

- 주문 #38: `ギフトセット`(¥8,800) + `DUSK オイルパフューム`(¥5,500), 송료 무료, 합계 ¥14,300(소비세 ¥1,300 포함)
- 상태 `processing`, 결제 완료(`paid`), 결제 방법 `stripe`, PaymentIntent 생성됨, 통화 JPY
- 로컬(HTTP, 웹훅 없음)에서도 카드 결제와 주문 확정까지 정상. Stripe API 확인: `livemode=false`

### 다듬기 (적용 완료)

- 결제 수단 이름: `Credit / Debit Card` → `クレジットカード / デビットカード` (`plugins/kapla-shop-tweaks`의 gettext 필터)
- Stripe Link 숨김: Stripe 샌드박스의 결제 수단 설정(Default configuration)에서 Link를 `off`로 변경했다. 이 설정은 Stripe 계정 쪽에 저장되므로 Git에는 남지 않는다. 운영(본 계정)에서도 같은 설정이 필요하다.
- 저장된 카드(`saved_cards`)를 꺼서 "카드 정보를 제공하면 …" 안내 문구를 없앴다.

### 남은 것

- Stripe 계정의 공개 사업자명이 샌드박스에서는 "<sandbox-name>"로 표시된다(일부 안내 문구에 노출될 수 있음). 필요하면 Stripe 대시보드 설정에서 Kapla로 바꾼다.
- Apple Pay와 Google Pay는 Stripe 샌드박스의 결제 수단 설정에서 끄고, 플러그인의 간편 결제 버튼(express checkout)도 껐다(사용자 결정). 샌드박스 기본 설정에는 일본에서 쓰지 않는 결제 수단(Bancontact, BLIK, EPS 등)이 켜져 있는 것으로 보이나, JPY·일본 주문에서는 체크아웃에 나타나지 않는 것을 확인했다(카드만 표시).
- 테스트 주문(#37, #38)과 테스트 고객 기록은 2026-10-26에 로컬 DB에서 삭제했다(주문 메모 포함, 상품 재고는 모두 20). 다음 주문 번호는 39부터다. 이전 전에 다시 테스트 주문을 넣었다면 같은 방식으로 정리한다.

## Stripe 테스트 키 설정 방법 (참고)

비밀 키는 채팅이나 Git에 남기지 않는 것이 원칙이다. (이번에는 사용자가 테스트용 샌드박스 키를 채팅에 붙여서 설정했으므로, 프로젝트를 마치면 Stripe 대시보드에서 키를 교체(Rotate)한다.)

1. [Stripe](https://dashboard.stripe.com/register)에서 계정을 만들고(직접), **테스트 모드**로 전환한다.
2. 개발자 → API 키에서 `pk_test_…`(공개 가능 키)와 `sk_test_…`(비밀 키)를 확인한다.
3. PowerShell에서 아래를 실행해 키를 입력한다(입력은 화면에 표시되지 않고, 본 키가 아닌 `pk_test_` / `sk_test_`만 받는다).

```powershell
.\scripts\stripe-test-keys.ps1
```

4. 결제 화면에서 테스트 카드 `4242 4242 4242 4242`(만료일은 미래 아무 날짜, CVC 아무 숫자)로 주문한다.

## 메모

- 키는 DB(`woocommerce_stripe_settings`)에만 저장되고, DB는 Git에 올라가지 않는다.
- 로컬에서는 Stripe 웹훅을 받을 수 없다. 카드 테스트 결제는 웹훅 없이도 확인할 수 있고, 웹훅은 홈서버에서 공개 주소가 생긴 뒤 등록한다.
- 송료·결제 설정은 `scripts/seed-checkout.php`로 다시 만들 수 있다. 무료 송료 시 유료 송료를 숨기는 처리는 `plugins/kapla-shop-tweaks`에 있다(테마에는 주문 로직을 넣지 않는다).
