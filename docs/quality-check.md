# 화면 품질 점검 기록

> 갱신 2026-10-26 · 로컬(`kapla.local`) 기준. 공개 후(홈서버, HTTPS, CDN)에는 다시 측정한다.

## 메인 페이지 구성

영상 히어로 → コレクション(おすすめの香り, 추천 상품 4개) → STORY(ブランドストーリー) → NEWS(최신 お知らせ 3건) → 푸터

- 추천 상품은 WooCommerce의 「おすすめ(별표)」가 켜진 상품이다. 관리자 화면의 상품 목록에서 별을 눌러 바꿀 수 있다. 시드 값: SALAR, DUSK, CEDAR 오일 퍼퓸, ギフトセット.
- 컬렉션 섹션과 뉴스 섹션은 패턴(`kapla/collection`, `kapla/latest-news`)이라 관리자가 순서나 문구를 바꿀 수 있다.

## 모바일 (375px)

- 15개 페이지(메인, 샵, 상품 상세, 카테고리, 브랜드, 店舗, FAQ, 문의, 특정상거래법, お知らせ, 카트, 결제, 마이페이지, 개인정보, 반품)에서 **가로 스크롤 없음**. 검색 결과 페이지도 같다.
- 헤더: 데스크톱은 왼쪽에 글자 메뉴 4개(ブランド, ショップ, お知らせ, 店舗) / 가운데 로고 / 오른쪽에 가는 선 아이콘 2개(계정, 쇼핑백). 600~899px부터는 햄버거 메뉴로 바뀐다.
- 열린 햄버거 메뉴: 크림 바탕, 좌우 여백, 큰 글자(18px)와 가는 구분선(예전에는 글자가 화면 왼쪽 끝에 붙어 있었다).
- 히어로 제목은 화면 폭에 따라 글자 크기가 줄어든다(375px에서 약 32px).

## 성능 (로컬, 참고용)

- 요청 92건, 전송 약 1.45MB(대부분이 영상 1.4MB). DOMContentLoaded 약 0.8초, LCP 약 0.74초(로컬 서버, 캐시 없음).
- Lighthouse 점수는 아직 측정하지 않았다(브라우저 도구 환경에서 직접 측정할 수 없어, 홈서버 공개 후 크롬에서 측정 예정).
- 상품 이미지는 AI 사진 12장(각 약 80~150KB, JPG). 상세 페이지의 큰 이미지는 1000px.

## 개발 중 알게 된 것

- **패턴 파일을 추가·수정한 뒤에는 `.\scripts\clear-cache.ps1`을 실행한다.** WordPress가 테마 패턴 목록을 캐시하는데, WP-CLI와 웹에서 테마 경로 표기가 달라 캐시가 2개 생긴다. 스크립트가 둘 다 지운다.
- 검색 결과는 `templates/search.html`이 그린다. 메인 검색은 `functions.php`의 `pre_get_posts`로 상품만 대상으로 한다. 사이트에 검색창은 아직 없다.
- 쿼리 문자열에 `?m=1`처럼 WordPress 예약어(`m`, `p`, `s` 등)를 쓰면 404가 나오니 테스트할 때 피한다.
