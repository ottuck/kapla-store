## 확인하지 못한 항목

- 두 곳 모두 PHP `memory_limit`, `max_execution_time`, 동시 프로세스 수 제한은 공식 자료에서 찾지 못했다.
- 두 곳 모두 WP-CLI 지원과 WooCommerce 동작 보증은 확인하지 못했다.
- 계약 전에 무료 체험이나 지원 문의로, 설치 후 관리자 화면의 「ツール → サイトヘルス → 情報」에서 PHP 메모리 한도와 실행 시간을 직접 확인한다.

## 개발 시 지킬 기준 (납품 환경 호환)

- PHP는 **8.3**을 기준선으로 한다. 현재 Local 사이트는 8.5.12이므로 납품 환경과 맞추려면 8.3으로 낮추는 것을 검토한다.
- WP-CLI와 SSH를 납품 환경에서 쓸 수 있다고 가정하지 않는다. 인수인계 문서는 관리자 화면만으로 따라 할 수 있게 쓴다.
- Docker, root 권한, 특수 PHP 확장에 의존하지 않는다. Docker 구성은 내 공개 데모용 인프라이며 납품물에 포함하지 않는다.

## 참고: 조사했으나 제외한 호스팅

ロリポップ!, さくらのレンタルサーバ, mixhost, CORE SERVER는 정보 부족 또는 예산 이유로 이 문서에서 제외했다. 시장 점유율은 공적 통계를 찾지 못했고, 블로그 집계는 출처마다 크게 달라 신뢰하지 않는다. 포트폴리오와 제안서에는 점유율 숫자를 쓰지 않는다.
